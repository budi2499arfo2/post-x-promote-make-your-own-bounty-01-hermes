This entry is an X post by @Hutanvbm quoting make.fun's make-your-own-bounty announcement post to promote it. The post lives at https://x.com/Hutanvbm/status/2125269649273360630, and this repository hands that address to the grader: the program copies the small `POST.json` file holding the post's URL into the output directory. The copy is deterministic — running the program twice produces identical bytes both times.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
